# 预览界面精简与交互设计

日期：2026-11-11。用户已确认布局 A、独立放大镜查找按钮及本文的产品交互规则，并补充查找输入焦点 bug；书面规格已获用户批准。详细实施计划见 `../plans/2026-11-11-preview-interface-implementation.md`。本阶段仅编写设计与计划，不修改应用代码，不创建分支、提交或发布。

## 1. 目标与已有状态

目标是在 Finder 的 Space 预览中提供紧凑的阅读界面：正文可以选中复制，适用格式默认渲染且可切回原文，查找通过独立图标按钮或快捷键使用。

当前宿主与 Finder 扩展共用 `Sources/QuicklookUI/PreviewWebController.swift` 和 `WebRenderer/src/`。已有 Markdown 渲染、JSON 格式化、JSONL 逐行视图、源码高亮、换行、行号、复制按钮和预览内查找。Markdown 已默认渲染；HTML 仍交给系统预览，从宿主直接打开则按普通源码处理。

用户选择的布局 A：辅助信息紧跟文件名，整条工具栏保持单行。最新交互稿为 `.superpowers/brainstorm/27220-1794410108/toolbar-layout-a-search.html`，在已选 A 布局上增加独立查找图标；早期 `toolbar-layout-v2.html` 与 `toolbar-layout-comparison.jpg` 仅保留为历史对比。这些只说明布局，不证明 Finder 中的输入、复制或 HTML 已实现。

## 2. 单行工具栏

- 仅隐藏“复制”按钮；查找保留独立图标按钮，同时支持 ⌘F。不额外删除任何现有功能，包括 JSONL 的模式切换。
- 文件名在前，格式、编码、大小、显示行数或记录数紧跟其后，以较小字号和较低视觉权重呈现。
- 工具栏右侧依次保留模式切换、换行、查找三个独立图标按钮。查看原文用代码图标，返回渲染用眼睛图标；换行用文字横线和折返箭头，避免与刷新、撤销混淆；查找用通用放大镜图标。
- 图标保留准确的中文悬浮说明、无障碍名称、键盘焦点提示和状态反馈。模式按钮按当前格式区分“查看预览”和“查看格式化内容”。
- 源码无替代模式时沿用现有逻辑，不显示模式按钮。Markdown/HTML 渲染态的换行按钮禁用；源码及 JSON/JSONL 文本视图可使用换行，默认开启。
- 窄窗口不让操作另起一行。按钮保持可操作尺寸；长文件名截断主体并保留扩展名，悬浮可看全名。
- 空间收紧时先省略编码，再省略行数/记录数，进一步不足时省略格式，优先保留文件名、大小和操作。完整元信息仍可通过文件名/信息区的悬浮说明查看，并为辅助技术提供完整文本；推测编码等异常提示不随元信息省略而丢失。
- 深浅外观继续跟随系统，正文排版与必要的异常提示保留。布局细节以真实窗口效果校准，不以交互稿像素值作为硬性约束。

## 3. 复制与查找

### 3.1 选区复制

- 通过正文选区与 ⌘C 复制普通文本，不提供一键复制按钮。
- Markdown/HTML 渲染态复制所选可读正文，不输出 Markdown/HTML 标记；原文态复制所选源码。JSON 格式化态复制格式化文本，原文态复制原文；JSONL 与其他源码同样遵守当前视图。
- 跨行、段落、代码块和表格选区保留合理的换行与分隔；源码保留其在当前预览中的字符、缩进、空行和换行结构，不混入行号、错误徽标、工具栏、资源提示或空行占位符。
- 没有正文选区时不自动复制整篇，也不清空剪贴板。正文获得焦点后，⌘A 只选正文；查找输入框中的 ⌘A/⌘C/粘贴保持标准编辑行为。
- 范围限于已读取、已显示的预览内容，不能把大文件前缀称为整份文件。

### 3.2 查找与新增必修 bug

**用户报告：打开查找后，无法正常在查找栏输入；按键实际上触发 Finder 的检索定位功能。该问题必须修复，保留查找按钮不能代替输入焦点修复。**

复现与验收环境必须包含真实 Finder Space 窗口。宿主和浏览器交互稿的成功不代表 Finder 通过。

- 点击工具栏的独立放大镜按钮可展开/收起查找栏，悬浮说明和无障碍名称为“查找（⌘F）”，并提供展开状态反馈。展开后输入框必须真正获得键盘输入焦点；收起时清空查询及高亮并把焦点交回正文。
- 在预览处于活动状态时，⌘F 始终展开或聚焦本项目的查找栏，不因查找栏已展开而将其关闭。
- 点击已展开的查找输入框后，可以连续输入英文、中文和符号，退格、左右移动和粘贴正常，不触发 Finder 的键入定位。
- 中文输入法组合期间不能因重绘、自动查找或焦点切换中断输入；组合完成后再按已提交文本更新结果。
- 保留当前视图的匹配高亮、计数、Enter 下一处、Shift+Enter 上一处。搜索范围仅为当前已显示内容，排除行号与状态标签。
- 查找栏提供关闭入口；Esc 优先收起查找并把焦点交回正文。查找关闭时保留系统的预览退出行为；输入法组合中的 Esc 先遵循输入法行为。
- 切换原文/渲染时，已展开查找栏保留查询并对新视图重搜；输入框正在编辑时不得意外把后续输入交回 Finder。
- 将该 bug 作为实施顺序中的第一个行为修复：先复现、记录 responder/焦点链与输入去向，再选择窗口内焦点/命令转发修正，并让放大镜按钮与 ⌘F 使用同一查找入口。当前代码只有网页 keydown/DOM focus，不能据此确认根因。
- 不引入全局键盘监听、额外辅助功能权限或常驻 helper。只在本应用预览的活动上下文处理命令和输入，不能吞掉其他窗口的按键。

## 4. 默认模式与 HTML 范围

| 类型 | 默认状态 | 可切换状态 |
| --- | --- | --- |
| Markdown | 渲染 | 原文 |
| HTML/HTM/XHTML | 静态渲染 | 原文 |
| JSON | 格式化 | 原文 |
| JSONL/NDJSON | 当前逐行记录视图 | 当前原文视图 |
| 配置、日志、源码 | 当前高亮原文 | 保持现状 |

每次加载新文件从默认状态开始，不增加跨文件模式记忆。原文切换不修改磁盘文件，已有格式错误提示及退回原文逻辑保留。

HTML 是本次新增能力：

- 支持静态标题、段落、列表、表格、代码和链接，并允许文档内嵌样式；不承诺依赖脚本、远程资源或外部样式表的网页保真。
- 文档内容与工具栏隔离，文档样式不能覆盖查找栏、图标或提示区。
- 文档脚本、事件处理器、表单提交、自动跳转、嵌套 frame、插件与自动网络请求禁用。用户主动点击网页/邮件链接仍通过现有的受控导航行为打开外部应用。
- 本地图片复用现有授权、路径限制、光栅类型、尺寸与总量预算，不扩大目录授权；受限资源显示简短可读提示。CSS 中的远程 URL、字体和图片不得绕开资源策略。
- 新增 `.html/.htm/.xhtml` 的识别和精确语义 UTType 声明；同步生成器目前对 HTML 的明确排除规则。继续禁止宽泛文本/二进制兜底，不改变默认打开应用，也不扩大 TXT/PDF/Office 的接管范围。
- 渲染失败时提供原文与简短原因。不能因渲染失败放开脚本或网络。

## 5. 组件边界与数据流

沿用现有 Swift 宿主/扩展共享架构，不做无关重构或更换渲染框架。

1. **有界加载与类型识别**：继续由 `PreviewPayload`、`TextLoader` 与类型清单负责内容、编码、大小和截断状态；增加 HTML 类型，不更改现有读取预算。
2. **受信预览外壳**：`PreviewWebController` 与主文档管理工具栏、查找、焦点、加载状态和原生剪贴板桥。原生桥继续只接受受信主 frame 消息。
3. **当前正文视图**：统一提供正文根、选区纯文本、限定正文的全选、查找和焦点恢复能力。源码/Markdown 可沿用当前主文档；HTML 使用无脚本的隔离文档容器。命令针对当前正文视图，不能假设 iframe 的键盘事件会冒泡到外壳。
4. **HTML 渲染单元**：负责限制文档行为、隔离样式、重写允许的本地图片并提供加载结果。建议由受控同源资源端点承载子文档，使用无脚本 sandbox 与独立 CSP；不要同时授予文档脚本与同源能力，也不要为内嵌样式放宽受信主页面的脚本限制。自定义 URL scheme 下的实际同源访问、CSP 和键盘行为必须用 WKWebView 验证后才能作为实现依据。
5. **资源处理**：`PreviewResourceHandler` 仅服务明确的受信资源路径、当前受控 HTML 文档和受限本地图片。受控 HTML 使用本次加载标识，关闭/换文件后失效；文档不能通过注入 `<base>`、CSP 或导航链接取得主文档权限。

数据流：文件 URL → 有界 payload → 共享预览外壳 → 当前正文视图；正文选区/查找命令 → 受信外壳 → 现有原生桥。HTML 内容只能被显示，不能自行调用原生动作。

## 7. 验证与完成标准

- **行为回归**：选区复制覆盖 MD 渲染/源码、JSON 格式化/源码、JSONL 和普通代码；包含大整数、中文、跨行、空行、代码块和表格。检查实际粘贴文字，而非仅看选区或“已复制”状态。
- **焦点专项**：Finder 首次打开与再次打开、点击正文、点击放大镜按钮展开/收起、点击输入框、⌘F 打开/聚焦、中文输入法组合、粘贴、Esc、切换模式后继续输入。确认查询进入本项目输入框，Finder 的选中项/键入定位未被触发；宿主也做同样检查。
- **HTML 专项**：HTML/HTM/XHTML 默认渲染与原文切换、文内样式隔离、本地图片授权/撤销、外链、脚本/事件属性/表单/自动导航/远程 CSS 和图片受限、畸形 HTML 可读退回，以及两种模式下的复制与查找。
- **布局检查**：至少覆盖 420、520、920 px 宽度，普通与长文件名，深浅色，渲染/源码与查找展开状态。工具栏保持单行，正文可读，操作不被挤出；辅助技术可识别图标功能。
- **自动检查**：复用 `WebRenderer/test/renderer.test.js`、Swift 核心测试和相关类型声明测试，补有价值的行为回归；生成资源检查与构建遵循仓库脚本。DOM 单测不能替代真实 WebKit、沙盒或 Finder 输入验收。
- **路由证据**：HTML 必须观察到本项目工具栏和可用的模式切换。注册表匹配、宿主成功或系统原生 HTML 显示均不单独算通过。
- 保留现有大文件、编码、JSON 精度/重复键、JSONL 坏行续读与资源限制的回归结果。记录本轮实测环境和未验证平台，不把本地测试推及所有 macOS/硬件。
