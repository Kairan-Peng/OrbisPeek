# 最终范围：不含查找功能的预览

> 2026-11-15 用户要求移除独立文档打开入口，1220 已按预览插件定位执行。查找仍移除；HTML 的当前 Finder 分发限制见 [最新计划](../plans/2026-11-15-preview-plugin-only.md)。以下入口描述属于当时范围。

用户最新指令：“先不做查找功能了，按没有查找功能的状态首尾吧”。本范围取代此前查找输入修复、Finder 放大镜交接及自动展开查找的验收目标，不再继续查找方案或实体 IME 调试。

- Finder 预览、宿主和独立阅读窗口均无查找按钮、查找栏或查找快捷键入口；⌘F 不展开查找。不提供复制按钮。
- 按 2026-11-14 用户补充要求，文件名由外层窗口标题展示，内部只显示紧凑单行辅助信息，保留适用的模式、换行图标。Markdown / HTML 默认渲染，可往返原文；JSON / JSONL、源码与日志已有模式保留。
- 正文选区可通过常规复制操作得到纯文本，复制不得混入行号、工具栏或其他装饰内容。保持现有静态 HTML、资源权限和主 / 子文档隔离。
- Finder Space 行为保持。HTML / HTM / XHTML 通过“打开方式 → OrbisPeek”进入独立阅读窗口，默认打开应用不变。正常 AppKit 文件打开接收、冷 / 热启动、设置窗口关闭后的接收和阅读窗口关闭清理保留。
- 删除不再需要的查找专用跨进程交接、静态标记及相关状态，不增加 helper、全局监听或权限例外。私有渲染辅助代码的清理以最小合理变更为限。

以 1207 候选重新安装并验证：签名 / 资源 / 唯一登记 / 原默认应用；真实 Finder Markdown 默认与原文切换、无查找入口；HTML 三种后缀的打开方式与渲染 / 原文切换；实际复制与既有格式回归。保留 1203、1205、1206 的可恢复备份和历史失败记录；查找被移出范围，不写成查找输入 bug 已修复。
