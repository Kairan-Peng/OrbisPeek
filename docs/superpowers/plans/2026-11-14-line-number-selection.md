1. [x] 用生产 WebKit 渲染合成多行文本，记录当前 user-select 支持、计算样式与跨行原生选区，建立失败对照。
2. [x] 采用能消除实际选择的最小修复，不以透明选区颜色掩盖问题；共享行号在源码、Markdown 原文、JSON / JSONL 中一致。
3. [x] 验证跨行、空行、换行 / 不换行、全选和正文复制投影，检查生成资源及相关运行时变更范围。
4. [x] 备份并替换本机安装，在真实 Finder 用合成文档拖选跨行正文，确认行号没有选中底色，正文选区和模式切换正常；记录验收与边界。
