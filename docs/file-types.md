# File types and Quick Look routing

Generated by `scripts/generate-types.py` from `Sources/QuicklookCore/Resources/file-types.json`. Do not edit this table directly.

The renderer recognizes **227 suffixes** across **86 groups**, plus **56 case-insensitive filenames**. The extension declares **193 exact UTIs**. These are recognition/registration counts, **not a claim that Finder has invoked the extension for every suffix**.

TXT, TEXT, HTML/HTM/XHTML, PDF, Office, CSV, SVG and media are intentionally left to macOS. `CMakeLists.txt` is an exact-name rendering rule, not a registration for all TXT files.

Type associations reuse FreeLook's MIT-licensed UTI mapping work (Neo Lee, 2026; commit `d3f002589917f51279b49ea8b12b3bb343dd82dc`) and the local routing baseline. See `THIRD_PARTY_NOTICES.md`.

## Registration boundaries

The preview whitelist uses exact semantic UTIs. It does not claim `public.data`, `public.content`, `public.plain-text`, `public.text` or `public.source-code` as catch-all preview entry points. Imported declarations add meaningful extension bindings where macOS versions or installed apps leave an otherwise known semantic type incomplete; product-owned exported declarations cover missing text-format routes.

No file association defaults are changed by generation or probing. Product declarations have the Viewer role and Alternate handler rank. Finder/provider precedence and third-party registrations still require runtime verification.

- **plain-config**: Filename recognition works after invocation; extensionless files and dotfiles are not guaranteed Finder routing surfaces.
- **dotenv**: Dotfiles are recognized by exact filename; no generic data/plain-text provider is claimed.
- **typescript**: The .ts/.mts preferred types can be MPEG media; media UTIs are deliberately excluded. Render these as code only when macOS supplies a semantic TypeScript UTI.
- **kotlin**: The imported org.kotlinlang.source route remained dynamic on the observed machine; a product-owned semantic fallback is declared.
- **fsharp**: The .fs suffix also names GLSL shaders. Only semantic F# UTIs are registered for this group; the preferred type must be checked on the target machine.
- **php**: The .php5/.php7 suffixes remained dynamic despite the imported public.php-script declaration on the observed machine. A product-owned plain-text PHP fallback is declared only for those two suffixes; real Finder selection must be rechecked after installation.
- **r**: The .r suffix can resolve to Apple Rez source. That unrelated identifier is not registered merely to improve R coverage.
- **groovy**: The imported org.gradle.source route remained dynamic on the observed machine; a product-owned semantic fallback is declared.
- **web-components**: The imported dev.svelte.source route remained dynamic on the observed machine; a product-owned semantic fallback is declared.
- **plist**: The text renderer handles XML plists; binary plist conversion is outside this registry and must be implemented separately before claiming it.
- **hcl**: Plain source view, without dedicated syntax highlighting in the first renderer.
- **nix**: Plain source view, without dedicated syntax highlighting in the first renderer.
- **zig**: Plain source view, without dedicated syntax highlighting in the first renderer.
- **elixir**: The .exs suffix can resolve to Logic sampler data. com.apple.logic.exs is deliberately excluded.
- **clojure**: EDN can resolve to Adobe DRM metadata. com.adobe.edn is deliberately excluded.
- **latex**: The .ltx suffix resolved to a dynamic preferred type and metadata-only Finder preview on the observed machine despite a public.tex candidate. A product-owned plain-text LaTeX fallback is declared only for .ltx; other LaTeX suffix declarations are unchanged and real Finder selection must be rechecked after installation.
- **nginx**: nginx.conf has an exact-name rendering override, but no reliable filename-only routing guarantee.

## Probe actual files

```sh
swift scripts/probe-routing.swift --create-fixtures .build/routing/fixtures --output .build/routing/before-install.json
swift scripts/probe-routing.swift --output .build/routing/samples.json samples
```

The probe records each real file's `URLResourceValues.contentType`, candidate extension UTIs, filename classification and exact whitelist match. It does not install the app, enable the extension, repair Launch Services, or prove which provider rendered a Finder window. After installing/enabling the built app, run the same probe and verify representative files with Space; record the selected provider separately.

The initial macOS 27.0.1 baseline was captured in `.build/routing/extension-baseline.json` before installing this project. Examples: `.jsonl/.json5` were dynamic; `.ts/.mts` preferred video types; `.exs` preferred Logic sampler data; `.r` preferred Rez source; `.edn` preferred Adobe DRM metadata. These are machine observations, not universal rules.
