# 个人目录默认引导

已完成并安装 0.1.1（1218）。个人目录默认位置、个人 / 其他目录取消、原生确认、退出 / 重开后的授权保留，以及宿主退出后的真实 Finder 图片和原文往返均通过。没有增加后台组件。

## 实现

- 首次无授权时，主入口为“允许读取个人目录…”，次入口为“选择其他目录…”。已有列表的图标 ＋ 提供同样两项，逐项移除保持。
- 默认路径使用当前 UID 的公开 `getpwuid_r` 账号记录，不使用会重定向沙盒容器的 `NSHomeDirectory()`，不拼接 `/Users/用户名`，不依赖 `$HOME`。查询最多使用 16 / 32 / 64 KiB 缓冲区；失败、相对路径、等效根目录或无效路径回退普通选择器。
- 账号路径仅用于设置 `NSOpenPanel.directoryURL`，不访问目录内容、不创建授权。只有用户点击原生“允许读取”、选择器返回 `.OK` 后，才以实际选中的 URL 调用原有只读书签流程；取消不会调用 grant。个人目录与其他目录使用同一授权流程。
- 选择器作为附着主页的原生 sheet 展示，显式操作时前置应用，同一时间只允许一个目录面板；主窗口不可用时才回退独立 modal。完成或取消后释放面板，允许再次选择。
- 保留原有目录记录，不清空真实授权模拟首次使用。不增加后台组件，不改变渲染器、复制、查找移除状态、图片路径策略或默认打开应用。

## 已完成检查

- 新增两项 Core 路径边界检查通过：支持自定义 / Network / 空格路径，拒绝缺失、相对、NUL 与等效根路径。
- 生产 `SetupContentView` 的纯值离屏快照覆盖空态、个人目录、多目录，600×600，无模型或真实授权存储依赖，布局无裁切。证据位于 `.build/validation/home-folder-onboarding/`。
- 最终 1218 的 30 份运行时冻结匹配；相对 1214，仅改两份 App 界面 / 选择器文件并新增账号路径解析文件。原渲染、复制、文件识别及目录持久化模块 hash 未变。1217 / 1218 两轮独立只读集成审查通过。
- 候选和安装的两个 bundle 签名通过，六份网页资源匹配，195 个精确预览类型、59 份安装文件及唯一偏好插件登记核验通过。原 1214 保留 ZIP 和可恢复 bundle。
- 1217 的独立 modal 在日志中可见，但电脑控制工具只能读取主页；用户切回后仍未能定位。因此 1218 改为附着主页的原生 sheet，随后实际读取、导航、取消与确认全部完成。1217 原始证据保留，没有把“已调用打开”当作成功验收。

## 真实验收

1. 签名沙盒 App 的“允许读取个人目录…”sheet 默认选中当前账号主目录，位置菜单的父级为 `Users`、`Macintosh HD`，没有定位到应用容器。取消后仍仅有原有的一条主目录授权。
2. “选择其他目录…”sheet 可实际导航到项目 `quicklook`，确认按钮可用，普通文件不可选；取消后未添加项目授权，原有列表保持。
3. 其他目录导航后，再次使用个人目录入口仍默认定位主目录，证明未被系统上次位置覆盖。实际点击“允许读取”后返回单页，无错误，也没有重复目录行。用户此前已有同一主目录授权，本轮使用原流程确认 / 刷新该项，没有删除真实授权来模拟首次授权。
4. 退出宿主，工具确认其未运行；重新打开后仍显示同一主目录。再次退出，并以进程记录确认宿主未运行后，在真实 Finder 对 `README.zh-CN.md` 按 Space，图标与正文可见，没有新增授权提示。原文态显示带 `width="96"` 的原始 `<img>` 标签，返回渲染后图标恢复。当前尺寸视觉正常，既有 96px 渲染布局及复制实现未修改；没有把本轮截图写成 Finder live DOM 的 CSS 精密测量。
5. 七份合成文件的默认打开应用前后相同，唯一偏好插件为安装目录内的扩展。结束时关闭测试预览，用户原有两个 Finder 标签和原活动标签 / 文件选择保留，留下新版主页供查看。

最终构建及真实操作证据目录为 `.build/validation/home-directory-onboarding-1218/`，机器摘要为 `acceptance-summary.json`。1218 初次插件登记尚无匹配，针对同一安装路径重试后复验通过，首次报告保留；没有全局缓存重置或终止 Finder。

首次空态使用生产纯值视图验收，实际生产选择器通过已有列表中的同一回调验证；不宣称清空过真实授权进行新用户完整首启测试。只读属性由原生 user-selected read-only entitlement 与只读书签选项核对，不在用户主目录尝试写入。此轮没有操作系统剪贴板或重新执行全套历史格式 / 复制验收；相应运行时源码和资源 hash 保持不变。仍为 Debug arm64 本地开发安装，其他系统、Intel、整机重启与公证分发未在本轮重验。Finder 原有的直接唤起限制仍保留手动回退，不把本次首次引导改动宣称成该问题已修复。
