# OrbisPeek 当前功能清单（2026-11-15）

当前已签名重装 0.1.1（1226）。“无后缀文本预览”改为 App 页面上的默认关闭开关；Finder 同一路径关闭 → 开启 → 关闭、退出宿主后的生效及重开 App 后状态保留均已通过，最终维持关闭。96 项 Swift 检查和 8 项离屏布局检查通过，见 [开关验收](extensionless-opt-in-validation-2026-11-15.md)。1225 无开关的文本与回退结果保留为[历史验收](unclassified-text-validation-2026-11-15.md)；任意陌生动态后缀仍不支持，HTML 使用系统预览。

## 文档与格式

| 功能 | 当前行为 |
|---|---|
| Finder 快速预览 | 选中文件按 Space，显示本扩展实际接管的文档；不要求宿主常驻 |
| Markdown | 标题、段落、列表、表格、只读任务列表、行内代码、代码块高亮和标题锚点；普通图片语法与受控 `<img>` 本地图片，支持有界整数宽高；默认渲染，可切换原文，见 [1209 图片验收](markdown-img-validation-2026-11-14.md) |
| HTML / HTM / XHTML | 使用系统预览；1225 从本扩展移除 HTML/XHTML 类型声明，真实 Finder 原生 HTML 回归通过。共享 HTML 渲染代码保留，不作为当前产品入口 |
| JSON | 默认格式化；保留大整数、重复键、键顺序和原始转义；解析错误显示位置并保留原文，可切换原文 |
| JSONL / NDJSON | 按原始行查看记录，显示行号、坏行与截断标记；坏行不影响后续记录，可切换原文；不是 JSON 树形编辑器或逐条美化视图 |
| 配置、源码与日志 | YAML、TOML、properties、INI、JSONC/JSON5、常见编程与标记语言等；有对应语法时高亮，部分类型按纯文本显示 |
| 未分类文本 | 默认关闭；用户在 App 开启“无后缀文本预览”后，对实际类型直接为 `public.data`、主要无后缀的文件尝试只读文本；仅严格 UTF-8 或明确 BOM 的 UTF-16/32，不猜旧编码。1225 的 Unicode、空文件和大文件前缀结果保留，1226 验证开关控制 |
| 读取拒绝回退 | 首次或关闭后重开 Space 时，二进制、编码拒绝和实际读取失败恢复系统原图标 / 元数据；已覆盖去后缀 PNG/PDF、GB18030 / 无 BOM UTF-16 样例、chmod000 及同路径文本变二进制后重开。不保证下一提供器渲染正文 |
| 文件识别 | 230 个唯一后缀、87 个格式组、56 个不区分大小写的文件名规则；另有 `.env.*`、`Dockerfile.*`、`Containerfile.*` 前缀规则。完整名单见 [类型清单](file-types.md) |

## 阅读与交互

| 功能 | 当前行为 |
|---|---|
| 紧凑文件信息 | 文件名由外层窗口标题提供，内部工具栏只显示格式、编码、文件大小、显示行数或 JSONL 非空记录数；窄窗口逐步收紧辅助信息，非视觉文档身份保留 |
| 模式图标 | Markdown 渲染与原文往返，JSON 格式化与原文、JSONL 记录与原文切换；普通源码 / 未分类文本不显示无用模式按钮 |
| 换行图标 | 默认自动换行，可在适用视图中切换；Markdown 渲染态禁用此按钮，新文件重置换行状态 |
| 自动行号 | 原文、源码、JSON、JSONL 自动显示行号；跨行拖选及全选排除行号，不显示行号选中底色；没有手动行号开关，见 [1219 修复](line-number-selection-validation-2026-11-14.md) |
| 系统外观 | 工具栏与源码随系统浅色 / 暗色变化；没有手动主题按钮 |
| 正文选区复制与全选 | 纯文本提取排除行号、工具栏和提示；渲染态处理可见正文、段落与表格间隔，原文态保留选中字符与换行。1208 已修复 Finder ⌘C 递归崩溃，渲染及原文实际复制 / 粘贴通过，详见 [修复验收](finder-copy-repair-2026-11-14.md) |
| 文档锚点 | Markdown 内部锚点跳转 |
| 外部链接 | 用户主动点击的 HTTP/HTTPS/mailto 链接交由系统打开；其他本地或自定义协议受资源边界限制 |

当前没有查找按钮、查找栏、查找快捷键入口，也没有复制按钮。右键菜单由 WKWebView/macOS 提供。Quick Look 外层的关闭、共享、全屏和“通过某应用打开”属于系统容器控件。

## 宿主、开关与目录权限

| 功能 | 当前行为 |
|---|---|
| 单页介绍 | 应用图标、名称、中英 slogan、目录管理和一个紧凑的“无后缀文本预览”开关，没有侧栏、格式介绍、安装自检、示例或诊断区 |
| 无后缀文本预览开关 | 默认关闭；缺失 / 损坏设置及从 1225 升级均不会自动开启。每个新请求读取共享设置，严格文本加载前再次检查，隐藏 / 恢复不能绕过关闭状态；更改后关闭并重新打开预览，宿主无需常驻 |
| 首次使用引导 | 主入口默认定位真实用户主目录，由用户确认一次只读授权；保留“选择其他目录…”与稍后设置，不强制弹出选择器；已有列表的 ＋ 提供同样两项，详见 [1218 验收](home-directory-onboarding-validation-2026-11-14.md) |
| 预览插件入口 | 日常文档入口为 Finder Space；本轮移除“打开方式 → OrbisPeek”文档声明及“打开文件… / ⌘O”，不提供宿主独立阅读器入口 |
| 本地图片授权 | 可选签名构建提供只读授权目录列表、添加及逐项移除；最多 32 个目录；扩展接收后持有自己的书签，宿主无需常驻，移除后重开预览生效 |
| 图片受限入口 | 实际本地图片加载失败才显示一条提示及授权入口；本机 Finder 无法直接唤起目录页时提供具体手动步骤；提示不进入正文复制。原 [1214 验收](permission-onboarding-validation-2026-11-14.md)中的独立阅读器入口属于历史范围 |

## 本地资源、编码和保护

- 支持文档目录内相对路径的 PNG、JPEG、GIF、WebP、HEIC/HEIF、BMP、TIFF；受限图片显示占位提示。仅解码首帧，不播放动画。
- 不加载远程图片、绝对路径图片、父目录或符号链接越界图片、SVG；HTML 外部样式、字体、媒体等受 CSP 阻止。
- 常规已支持格式保留 UTF-8/16/32 BOM 识别、无 BOM UTF-16 与旧编码推测并提示。1225 未分类兜底只接受严格 UTF-8 或明确 BOM 的 UTF-16/32，不沿用旧编码推测；拒绝二进制及不能无损解码的文本。
- 大文件有界前缀阅读：原生每次最多读 512 KiB + 4 字节，常规最多显示 4,000 行、JSONL 记录视图 2,000 行；过大文本或超长行退回纯文本，避免昂贵高亮。
- JSON 嵌套限 128 层；图片单文件最多 8 MiB、原图最多 4,000 万像素、输出最大边 2,048 像素；每次预览最多 32 次图片加载、输出图片总量 32 MiB。
- 本地处理，不执行文档自带脚本或表单，不自动请求文档网络资源；Markdown 仅将受控 `<img>` 转为图片（`src`、`alt`、1–1600px 的整数宽高），其余内嵌 HTML 显示文字；HTML 文档使用白名单重建与受控子文档。

## 边界

- 194 项静态预览声明保持：193 个语义类型 + 直接 `public.data`。开关关闭时在运行时返回系统，不读取未分类文档正文；HTML/XHTML 不在预览声明中，继续使用系统预览。1225 的七份原默认打开应用保持记录不等同本轮重验。
- 共享设置使用有 4 KiB 上限的版本化原子文件，每个新请求实际读取，不依赖宿主进程缓存。未配置 App Group 的构建不可开启；此设置不新增文件授权或后台组件。
- `public.data` 仅接收实际类型直接相等的请求，不是祖先通配。无后缀 / dotfile 也可能有其他类型，不能保证全部接管；任意陌生 `dyn.*` 后缀不在生产声明中。
- 系统原图标 / 元数据回退只覆盖首次或关闭后重开的读取阶段拒绝。异步 WebKit 失败仍使用本应用错误界面；隐藏 / 恢复期间文件变坏时无法重新交付 Quick Look 完成回调，显示“无法恢复预览。请关闭后重新按空格预览。”，关闭重开后重新执行严格策略。
- 类型识别数量不保证 Finder 调用；UTType 冲突、其他 provider、无后缀和 dotfile 的系统类型均可能影响接管。
- TXT/TEXT、PDF、Office、CSV、SVG、媒体等保留系统能力，没有实现办公渲染引擎；不改默认打开应用。
- 普通 ad-hoc 构建没有可选目录授权和自动回执；当前为 Debug arm64 开发安装，其他系统 / Intel、整机重启后的权限恢复未完整实测。
- 本轮没有触碰剪贴板或重验 Finder 复制 / 粘贴；复制与渲染六份网页资源保持 1219，不将资源一致性当作新的实体复制验收。没有新增目录授权、后台组件或独立打开入口，查找继续移除。
- 构建、类型生成、打包 / 可选公证、probe 与覆盖率报告属于开发验证设施，不算日常产品功能。

## 陌生后缀与后续边界

1225 无开关时的文本和读取拒绝回退已实测，1226 改为默认关闭且用户明确开启。隔离实验中，三个父类 `public.data` / `public.item` / `public.content` 均未匹配未知动态后缀；精确完整 `dyn.*` 正对照只证明特定枚举类型可以分发与读取拒绝回退，不能扩展成任意陌生后缀支持。生产只保留直接 `public.data` 的可选尝试，其余陌生动态类型保持系统行为，后续若扩大覆盖需另行验证。
