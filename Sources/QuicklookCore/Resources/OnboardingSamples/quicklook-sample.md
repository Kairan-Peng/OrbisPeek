# Quicklook 首次预览检查

欢迎使用 **Quicklook**。这份样本只在本机显示，不访问网络。

## 确认预览界面

顶部应显示 **MARKDOWN**、文件名和编码，并提供“查看原文”“换行”“复制”“查找”。只有正文排版，并不能证明 Finder 选择了 Quicklook。

- [x] 标题、表格和任务列表可阅读
- [x] 代码块有语法颜色
- [ ] 点击“查看原文”，再切回预览
- [ ] 点击“查找”，搜索“中文”

| 内容 | 预期结果 |
| --- | --- |
| 中文与 emoji | 你好，世界。🧭 |
| JSON 大整数 | 保留完整数字 |
| 目录图片 | 授权后显示下方棋盘 |

```json

```
